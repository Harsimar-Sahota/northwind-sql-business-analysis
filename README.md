# Northwind SQL Business Analysis Project

## Overview

This project demonstrates SQL-based business analysis using the Northwind sample database. It focuses on solving common business reporting and analytical problems through SQL queries involving joins, aggregations, subqueries, common table expressions (CTEs), and data updates.

## Objectives

- Analyze customer orders and sales data
- Generate business insights using SQL
- Practice SQL techniques commonly used in business analysis

## Database

- MySQL

## SQL Concepts Demonstrated

- SELECT
- INNER JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions (SUM, AVG)
- HAVING
- Subqueries
- Common Table Expressions (CTEs)
- UPDATE statements

## Business Questions Solved

1. List all orders with customer information.
2. Calculate total quantity ordered for each product.
3. Calculate percentage of total revenue by product.
4. Identify the top 5 customers by total spending.
5. Update discounts for discontinued products.
6. Calculate average freight cost by shipper.
7. Generate monthly sales by employee.
8. Identify shipping companies handling the most high-value orders.
9. Identify the highest-performing employee in each product category.
